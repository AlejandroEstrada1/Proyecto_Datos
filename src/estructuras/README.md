# Estructuras de Datos Implementadas

Proyecto: Sistema de Gestion de Estibas.

Estructuras usadas segun la rubrica:

1. Cola
   - Uso: gestion de pedidos pendientes.
   - Criterio: primero en entrar, primero en salir.

2. Lista Enlazada
   - Uso: plan del dia e historial de pedidos procesados.
   - Criterio: recorrido secuencial de pedidos.

3. Arbol Trie
   - Uso: busqueda eficiente de productos en inventario.
   - Criterio: busqueda por prefijos.

4. Heap de Prioridad
   - Uso: priorizacion de pedidos por nivel ALTA, MEDIA y BAJA.
   - Criterio: el pedido con mayor prioridad queda primero.

5. Grafo
   - Uso: rutas de despacho entre bodega y clientes.
   - Criterio: nodos como ubicaciones y aristas ponderadas por tiempo.
